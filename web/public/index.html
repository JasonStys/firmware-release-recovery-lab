    Help, data and interpretation

    Every run initializes fresh fictional devices with the original Rust LabStore. Saved history preserves inputs/results, not a live fleet. Each timeline row shows actual recovered before/after state. Boot chooses a slot; it never executes image bytes. Confirm/fail are supplied assumptions, not sensor readings. Named fault injection models metadata boundaries, not physical power loss or hardware reliability.

    Workflow inputs are limited to256KiB,64 devices,64 transitions and64KiB per inert image. Desktop campaigns use1..5 iterations (12 original scenarios each). An interrupted or blocked result is useful negative evidence, not a successful deployment. Physical temporary-root hashes and measured wall time may change on rerun.

    Workspace data is plaintext for this trusted OS user. No cloud, account, telemetry, ad or remote API is used. Back up the stopped external workspace. History holds at most1000 records/100MiB; export and explicitly delete selected records to free space. Quit waits for actual owned work before releasing the lock. Unsigned portable packaging is not an installer or clean-machine certification.
